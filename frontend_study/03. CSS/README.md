# 1. CSS 소개 및 기본 개념 설명

## CSS 란?
- CSS (Cascading Style Sheets) : HTML이나 XML로 작성된 문서의 스타일을 꾸미는 언어
- 기본적으로 웹 페이지의 레이아웃, 색상, 글꼴, 크기 및 간격과 같은 시각적인 표현을 담당
- 선택자와 선언으로 구성
- 선택자 (Selector) : 스타일을 적용할 HTML 요소를 선택하는 역할
- 선언 (Declaration) : 선택된 요소에 적용할 스타일 속성과 값

## HTML과 CSS의 관계
- HTML과 CSS는 웹 페이지를 만들기 위한 핵심적인 두 가지 언어
- (뼈대) HTML은 웹 페이지의 구조를 정의
- (뼈대에 옷) CSS는 그 구조에 스타일을 부여
- 분리된 구조는 유지보수성을 높이고, 일관된 디자인을 적용하는 데 도움
